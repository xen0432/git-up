# GitUP

Platform manajemen repositori GitHub berbasis web.

## Fitur
- Login dengan Personal Access Token (ghp_)
- Upload multiple file ke repositori
- Buat repositori baru (public/private)
- Hapus repositori
- Riwayat aktivitas
- Terminal log real-time

## Teknologi
- HTML
- CSS
- JavaScript
- Tailwind CSS
- Lucide Icons
- GitHub REST API

## Cara Pakai
1. Buat Personal Access Token di GitHub (izin repo)
2. Masukkan token di halaman Login
3. Mulai kelola repositori Anda
