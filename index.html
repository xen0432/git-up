Kenapa Memilih GITUP

Aplikasi pengelolaan GitHub berbasis peramban untuk kebutuhan pengunggahan berkas, folder, dan pembuatan repositori langsung tanpa konfigurasi terminal.

1

Cepat

Berjalan langsung menggunakan GitHub REST API. Pengunggahan berkas jamak atau pembuatan repositori selesai dalam beberapa detik.

2

Aman

Token akses pribadi disimpan murni di sisi peramban lokal perangkat Anda dan tidak melalui server perantara mana pun.

3

Intuitif

Dilengkapi pantauan progres langsung (*Live Monitor*), dukungan pengunggahan folder utuh, dan pengelolaan daftar repositori.

    Autentikasi Akun
    Cara Mendapatkan Token GitHub:
    1. Masuk ke akun github.com Anda.
    2. Klik foto profil di kanan atas, pilih Settings.
    3. Gulir ke menu paling bawah di sebelah kiri, pilih Developer settings.
    4. Pilih Personal access tokens lalu klik Tokens (classic).
    5. Pilih Generate new token > Generate new token (classic).
    6. Beri nama catatan token dan centang hak akses repo serta delete_repo.
    7. Klik Generate token di bagian bawah, lalu salin token yang diawali ghp_ dan tempel pada form di atas.
