Gambaran Umum

GitUp dibangun untuk memudahkan sinkronisasi file lokal ke repositori GitHub tanpa memerlukan Git CLI terpasang di komputer Anda.

Semua aktivitas komunikasi data langsung diarahkan ke REST API resmi milik GitHub secara transparan dan terenkripsi.

Standar Keamanan

Token Anda hanya berada di peramban dan tidak disimpan di pangkalan data luar manapun.

Pastikan token yang Anda buat di GitHub memiliki izin cakupan repo agar semua fungsionalitas pembuatan dan unggah berjalan normal.
